# Scripts used on startup

## `startup.py`

Will run when the machine starts.

## `constants.py`

Variables required amongst scripts.

## `boot_video.py`

Run video on startup.

## `transfer.py`

Insert save_config section from `/printer.cfg` and canbus uuids from `/canbus_uuids.json` on `/backups/printer.cfg` and move it to `/printer.cfg`.
